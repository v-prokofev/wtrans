# DVU-01 Sensor Emulator

Эмулятор датчика ветра ДВУ-01 для отладки прибора **WindTrans** без физического датчика.

## Требования

- Python 3.8+
- PySide6
- pyserial

```
pip install PySide6 pyserial
```

## Запуск

```
python emulator.py
```

## Использование

1. Выберите COM-порт, к которому подключён WindTrans (через RS-485 / USB-UART).
2. Выставьте скорость соединения (по умолчанию **9600** — как на датчике DVU-01).
3. Задайте скорость ветра (0…60 м/с) и направление (0…359°) слайдерами или прямым вводом.
4. Нажмите **▶ Пуск** — эмулятор начнёт слушать порт.
5. В консоли отображаются все входящие команды и ответы.

## Протокол

Эмулятор корректно реагирует на все команды, которые отправляет WindTrans:

| Команда (от прибора) | Ответ эмулятора |
|---|---|
| `@1 AMES 0 0\r\n` | *(нет ответа)* |
| `OPEN 1\r\n` | `1, 1.0.0, DVU-01 SESSION OPENED >` |
| `VER\r\n` | `DVU-01 ver 1.0.0` |
| `M 1\r\n` | `0 5.00 4.98 5.12 4.87 0 180 181 182 179` |
| `@1 M\r\n` | `@1:0 0 5.00 4.98 5.12 4.87 0 180 181 182 179` |

## Настройки

- **Шум**: включает случайную флуктуацию (~±0.05 м/с, ~±0.5°) для реалистичности.
